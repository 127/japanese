# Правила для агента в этой папке

## !_kanji_voc_all.pdf

Для этого файла важен порядок картинок: они должны идти строго как в учебнике (golovnin_japanese.pdf), кандзи и словари вперемежку по урокам, а не так, как удобнее для заполнения страниц.

Порядок: voc001, voc002, voc003, voc004, voc005, voc006, kanji001, voc007, voc008, kanji002, voc008b, voc009, voc010, kanji004, voc011, voc012, voc013. kanji003 (хитоцу, футацу … — не из учебника) стоит последней. voc008b вырезан из учебника (стр. 71, «Иероглифическое написание введённых ранее слов»).

Менять порядок ради экономии места нельзя, даже если на странице остаётся пустое место. Пустого места при этом стоит избегать другими способами: масштабом картинок и разбивкой по страницам.

## !_kanji_all.pdf

Отдельный файл только из таблиц кандзи: kanji001, kanji002, kanji004. kanji003 (хитоцу, футацу …) сюда не входит — это не кандзи.

## Сохранение файлов в эту папку

После каждого сохранения файла в эту папку нужно проверять, что локальная копия совпадает с только что созданной версией (например, по md5), и только потом сообщать, что файл обновлён.

Причина: при записи обновлённого файла под тем же именем сюда уже попадали устаревшие копии, хотя в чате показывалась свежая версия. Если копии не совпали — пересохранить и проверить ещё раз.

## Поиск материалов в интернете

В этом проекте не нужно останавливаться и ждать пользователя, если нужный сайт недоступен из рабочей среды: сразу открывать свой встроенный браузер, находить и забирать нужное оттуда и двигаться дальше. О сделанном сообщать по факту.

Графику порядка черт брать из AnimCJK (см. раздел про !_kanji_strokes.pdf), а не рисовать черты самому.

## !_kanji_strokes.pdf — порядок черт

Что это: пошаговые схемы порядка черт для 50 иероглифов из !_kanji_all.pdf, в порядке таблиц учебника. Для каждого знака — иероглиф целиком, затем по кадру на черту: ненаписанные черты бледные, написанные серые, новая чёрная, рядом с ней красная стрелка — направление письма.

Откуда графика: единственный источник — AnimCJK, японский набор (https://github.com/parsimonhi/animCJK, папка `svgsJa`, файл `<десятичный код знака>.svg`). В нём есть все дзёё- и дзиммэйё-кандзи, порядок черт японский. Из файла берутся контуры черт и осевые линии (от начала черты к концу); стрелки строит скрипт по осевым линиям. Викисклад и KanjiVG для этого файла больше не используются.

Как импортировано: файлы скачаны напрямую с GitHub (raw.githubusercontent.com) и лежат без изменений в `_strokes_src/animcjk/`.

Сборка: `python3 _strokes_src/build_strokes.py` из корня репозитория — пишет `!_kanji_strokes.pdf`. Нужен Python с пакетом playwright и его Chromium (`pip install playwright && playwright install chromium`). Чтобы добавить иероглиф, дописать его в строку `K` в скрипте в порядке учебника и запустить скрипт: недостающий файл AnimCJK он скачает сам. Подробности — в комментарии в начале скрипта.

Лицензия: SVG-файлы AnimCJK распространяются по Arphic Public License; шапка с лицензией сохранена в каждом файле, удалять её нельзя.

Размеры, которых нужно придерживаться всегда:
- Все иероглифы на всех страницах одного размера: кадр 37,6 pt (около 13 мм).
- Лист A4, поля 8 pt со всех сторон; промежуток между группами в строке 0,45 кадра, между строками 0,22 кадра.
- Сейчас 2 страницы. При добавлении новых иероглифов размер не менять — добавлять страницы.
- Никакого текста на страницах.
