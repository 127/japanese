# Правила для агента в этой папке

## !_kanji_voc_all.pdf

Для этого файла важен порядок картинок: они должны идти строго как в учебнике (golovnin_japanese.pdf), кандзи и словари вперемежку по урокам, а не так, как удобнее для заполнения страниц.

Порядок: voc001, voc002, voc003, voc004, voc005, voc006, kanji001, voc007, voc008, kanji002, voc008b, voc009, voc010, kanji004, voc011, voc012, voc013. kanji003 (хитоцу, футацу … — не из учебника) стоит последней. voc008b вырезан из учебника (стр. 71, «Иероглифическое написание введённых ранее слов»).

Менять порядок ради экономии места нельзя, даже если на странице остаётся пустое место. Пустого места при этом стоит избегать другими способами: масштабом картинок и разбивкой по страницам.

## !_kanji_all.pdf

Отдельный файл только из таблиц кандзи: kanji001, kanji002, kanji004. kanji003 (хитоцу, футацу …) сюда не входит — это не кандзи.

## Сохранение файлов в эту папку

После каждого сохранения файла в эту папку нужно проверять, что локальная копия совпадает с только что созданной версией (например, по md5), и только потом сообщать, что файл обновлён.

Причина: при записи обновлённого файла под тем же именем сюда уже попадали устаревшие копии, хотя в чате показывалась свежая версия. Если копии не совпали — пересохранить и проверить ещё раз.

## Поиск материалов в интернете

В этом проекте не нужно останавливаться и ждать пользователя, если нужный сайт недоступен из рабочей среды: сразу открывать свой встроенный браузер, находить и забирать нужное оттуда и двигаться дальше. О сделанном сообщать по факту.

Графику порядка черт сначала искать в готовых базах (Викисклад — проект Stroke Order Project, файлы вида 字-jbw.png / 字-bw.png; KanjiVG), а не рисовать самому.

## !_kanji_strokes.pdf — порядок черт

Что это: пошаговые схемы порядка черт для 50 иероглифов из !_kanji_all.pdf, в порядке таблиц учебника.

Откуда графика:
- 47 знаков — готовые картинки Викисклада (Commons: CJK Stroke Order Project). Файлы вида `字-jbw.png` (японский вариант), а если его нет — `字-bw.png` (общий). Общий вариант взят для 方 友 地 私 図 英 東 室 連 書 第 教 語 科.
- 戸, 洋, 紙 — на Викискладе картинок нет; нарисованы в том же стиле из KanjiVG (github.com/KanjiVG/kanjivg, файлы kanji/<код>.svg).

Как импортировано: commons.wikimedia.org и upload.wikimedia.org из рабочей среды были закрыты, поэтому картинки открыты во встроенном браузере, собраны в одну полосу и сняты снимками экрана в натуральном размере (1 пиксель картинки = 1 пиксель снимка). Если доступ к Викимедии есть — качать оригиналы напрямую через API (`action=query&prop=imageinfo&iiprop=url`).

Исходники лежат в `_strokes_src/`: `sop_sprite.png` (все 47 полос одна под другой), `sop_meta.json` (знак, смещение по вертикали, ширина, высота, j/b), `miss_*.png` (три дорисованных знака), `nstrokes.json` (число черт), `sopbuild.py` (сборка PDF: `python3 sopbuild.py out.pdf 2`).

Если нужного иероглифа на Викискладе нет: запустить в `_strokes_src` скрипт `draw_missing.py` (`python3 draw_missing.py 字`). Он рисует полосу в стиле Викисклада из данных KanjiVG (`kvg/<код>.svg`, недостающий файл скачивает сам), сохраняет `miss_<код>.png` и дописывает знак в `miss.json` и `nstrokes.json`. Подробности и зависимости — в комментарии в начале скрипта. Так сделаны 戸, 洋, 紙.

Размеры, которых нужно придерживаться всегда:
- Все иероглифы на всех страницах одного размера. Масштаб каждой полосы считается по шагу кадра (ширина полосы / число кадров в первом ряду), а не по высоте картинки: шаг кадра = 37,6 pt (около 13 мм) для всех знаков.
- У двухрядных полос кадров в первом ряду: 学 8, 連 6, 書 9, 第 10, 教 9, 語 9.
- Лист A4, поля 8 pt со всех сторон; промежуток между группами в строке 0,45 шага, между строками 0,22 шага.
- 2 страницы. При добавлении новых иероглифов размер не менять — добавлять страницы.
- Никакого текста на страницах; зелёные точки и красные стрелки оставлять как в исходных картинках.
